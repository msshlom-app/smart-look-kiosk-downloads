# Smart Look — Android Kiosk Downloads

Official Android APK distribution repository for **Smart Look**.

Smart Look is a family-managed display system designed to present useful information, messages, reminders, and medication schedules on dedicated Android tablets.

## Purpose

This public repository is used exclusively for distributing approved, signed Android installation packages (APK).

The application source code, signing keys, credentials, and backend configuration are maintained separately in private systems.

## Releases

Approved installation packages will be published under **GitHub Releases**, with version numbers and release notes.

## Installation and Security

- Install APK files only from approved releases.
- Verify the package version and signing certificate before deployment.
- Android Device Owner / kiosk provisioning requires a supported setup procedure.
- Pairing each tablet with a family and screen requires authorization through Smart Look.
- QR-based provisioning is under development and has not yet been fully validated.

## Current Status

**Development and testing. Not yet approved for production deployment.**

Do not factory-reset or reprovision an existing working tablet without a verified recovery plan.
